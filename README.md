# TaskFlow — Веб-сервис управления задачами (Go + PostgreSQL)

Полнофункциональный веб-сервис для управления рабочими задачами с системой авторизации, ролевой моделью доступа (RBAC) и мягким удалением записей (Soft Delete). Написан на стандартной библиотеке Go (`net/http`, `database/sql`) без тяжелых фреймворков.

## Технологический стек
* **Backend:** Go (Golang)
* **База данных:** PostgreSQL (драйвер `lib/pq`)
* **Безопасность:** Хеширование паролей (`bcrypt`), защита от SQL-инъекций (параметризованные запросы), защита от XSS (`html.EscapeString`), контроль прав доступа (IDOR protection) и Cookie-сессии.
* **Frontend:** Server-Side Rendering (HTML5 / CSS3)

## Основной функционал
* **Регистрация и авторизация:** Безопасное хранение паролей, валидация данных и управление сессиями через HTTP Cookies.
* **Полный CRUD для задач:** Создание, просмотр, редактирование и мягкое удаление задач (`status = '1'`) с привязкой к конкретному пользователю.
* **Быстрое изменение статуса:** Обновление этапа выполнения задачи (`новая`, `в процессе`, `выполнено`) прямо из карточки в профиле.
* **Панель администратора (`/admin`):** Разграничение ролей (`user` / `admin`). Администратор может просматривать задачи всех пользователей (через SQL `JOIN`) и модерировать их.

## Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd taskflow
   ```

2. **Подготовьте базу данных PostgreSQL:**
   * Создайте базу данных `taskFlow`.
   * Выполните SQL-скрипт из файла `schema.sql` для создания таблиц `users` и `tasks`.
   * При необходимости обновите параметры подключения в файле `db.go`.

3. **Установите зависимости и запустите сервер:**
   ```bash
   go mod tidy
   go run .
   ```

4. **Откройте в браузере:** `http://localhost:8080`
